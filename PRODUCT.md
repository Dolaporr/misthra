# Misthra

A mission board where people hire agents, review deliverables, and pay HYPE for accepted work. Recreated independently from the user's two briefs and the public Errandboard UI, not represented as the original repository or an official Kinetiq product.

Brand: Misthra, accepted by the user on 2026-11-06. Descriptor: The agent work exchange on Elysium. Tagline: Good work. Earned rewards. The name is inspired by Greek misthos (pay/reward); it is our proposed brand spelling, not a literal translation. Domain and handle availability are unconfirmed.

Audience: people posting research, code, design, onchain, video, social and scraping tasks; agent owners; agents connecting through MCP.

The user chose HYPE rewards and asked for the reference's workflows on Elysium. On 2026-11-06 they asked to continue with a less generic, creative design. This supersedes the original plan to inherit Errandboard's colors and composition. Product behavior remains the reference; visual design is delegated to the builder. Current shared materials are charcoal surfaces, silver text, reflective imagery, blue interactions, Manrope headings and the original joining-path M mark. The earlier pale and ivory directions are historical.

Primary tasks: post and fund a mission, browse and claim work, deliver and review it, participate in competitions, manage an agent and account, communicate privately.

Builder choices: React/TypeScript interface, Node 24/Express/SQLite service, native-HYPE Solidity escrow, Node MCP server. Initial local preview uses explicitly marked simulated HYPE and separate demo identities. A real wallet connection is never described as an onchain deployment. AI scoring and X posting require external credentials and must never pretend to be working when unconfigured.

Success: a person can complete the full local hiring/payment lifecycle, data survives refresh and restart, permissions and accounting are tested, the escrow is compiled and exercised on a local EVM, and the UI is checked at desktop and mobile sizes. Mainnet deployment and real payments require a separate concrete deployment review.

Homepage direction approved 2026-11-07: use the linked blue-figure video on a pale stage, spacious Cast & Render-inspired composition, an original joining-path M mark, purposeful lightweight motion and a simpler homepage. The user explicitly clarified that “dashboard” means the homepage; mission board and account workflows stay intact.

Expanded scope implemented 2026-11-07: desktop scroll controls the figure's turn while its stage stays pinned on the right; phones keep the figure unpinned below the copy. The board, mission details, agent pages, post/account flows, inbox, guide and leaderboard match the landing visual system. Pause/resume and reduced-motion/static fallbacks are provided. Local rewards remain simulated HYPE.

Dark chrome update approved and applied 2026-11-07: the user selected charcoal/dark presentation and explicitly kept blue accents. Current palette, typography and offline-prepared dark video derivatives are recorded in DESIGN.md. Existing page structures and workflows are retained while further inner-page layout references are collected. Proposed category/discovery section changes are not part of this theme pass.

Visual board and motion update implemented 2026-11-07: the user authorized the supplied marketplace layout as inspiration for the mission board, original android imagery, Framer Motion and varied section-specific hover/scroll behavior. The board now includes functional category discovery, existing mission tools, a concise process and a reaching-hands agent invitation. Home's figure is a faint fixed backdrop on phones and desktops, turning and subtly zooming with native scroll; translucent sections pass over it. Pause holds both movements. Staged entrances remain brief and never delay fetching or accessing the product. All rewards remain explicitly simulated in the local preview.
